首次发布 Chrome / Edge 的纯浏览器抖音视频下载扩展。

### 功能

- 点击扩展图标读取当前视频、实际分辨率、时长和可选清晰度。
- 默认选择当前可用的最高画质；检测到更高画质需要登录时，仅在弹窗提示。
- 用户可直接下载未登录时可用的画质，扩展不操作登录或读取 Cookie。
- 下载前核对视频编号、实际尺寸和最新地址，避免自动连播后误下载。
- 使用浏览器「另存为」，可选择 OneDrive 或其他本地目录；保留同名旧文件。
- 仅申请 activeTab、scripting、downloads 权限；无需本地助手或 AI 服务。

### 安装

下载附件 `douyin-video-extension-0.1.0.zip` 并解压。在 `edge://extensions` 或 `chrome://extensions` 开启开发人员模式，选择「加载解压缩的扩展」，选中含 `manifest.json` 的文件夹。固定扩展后，在抖音视频详情页点击图标使用。

`SHA256SUMS.txt` 提供安装包 SHA-256 校验值。GitHub 自动生成的 Source code ZIP/TAR 为完整源码，不是精简安装包。

### 验证与范围

- 14 项自动化测试、Manifest/文件引用检查和弹窗界面检查已通过。
- 清晰度控件结构已与真实抖音页面核对。
- 尚未在 Chrome / Edge 中加载本扩展执行真实下载，安装后的权限授予、画质切换和另存为流程仍需验证。
- 本版支持视频详情页及带 modal_id 的页面中的 HTTPS MP4 直链；不支持图文集、直播或分段流。
